# Demo media

These clips are trimmed and re-encoded from Blender Foundation open movies,
used only as local/RTSP test sources:

- **Big Buck Bunny** — © Blender Foundation | peach.blender.org, CC BY 3.0
- **Sintel** — © Blender Foundation | durian.blender.org, CC BY 3.0

They are not surveillance footage; they are open-licensed demo content so the
project can be run and screenshotted without exposing real camera feeds.
